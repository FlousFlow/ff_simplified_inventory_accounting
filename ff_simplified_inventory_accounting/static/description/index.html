Simplified Inventory Accounting for Odoo 18

Odoo 19-like product category accounting, with Odoo's native accounting engine

The problem

In Odoo 18 a Product Category exposes many technical stock-accounting fields: Inventory Valuation, Costing Method, Stock Journal, Stock Input / Output / Valuation accounts. Forgetting to configure them leads to incorrect stock valuation and broken accounting.

The solution

The user only selects Sales Account, Cost of Goods Sold and optionally a Costing Method. Everything else is configured automatically from a central per-company configuration. Odoo keeps creating the accounting entries — no duplicate engine.

Key benefits

  • Simpler Product Category configuration
  • Automatic technical stock accounting
  • Prevents missing inventory accounts
  • Works for new and existing categories
  • Centralized per-company configuration
  • Multi-company support with full isolation
  • Preserves the standard Odoo accounting engine
  • Accounting Status + Health Check for easy audit

Installation

odoo -d DB_NAME -i ff_simplified_inventory_accounting --stop-after-init

Then configure under Settings → Invoicing → Simplified Inventory Accounting.
